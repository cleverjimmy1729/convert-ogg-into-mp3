Respect original copyright. After conversion, this is for personal use only; commercial use is strictly prohibited!!!
The purpose of this script is to convert .ogg files to .mp3 files, with programming assistance from deeseek.

Usage
STEP1 Save this script on the desktop and name the file ogg2mp3_batch.
STEP2 Press Win+R to open PowerShell.
STEP3 cd (desktop path)
STEP4 python ogg2mp3_batch.py -i "path to be converted" -o "path to save the converted files" -r -j 8
STEP5 Wait for the conversion to finish :-)
